# Walk motion source

The walk cycle is retargeted from subject 136, motion `136_22` (Normal Walk) in the
[CMU Graphics Lab Motion Capture Database](http://mocap.cs.cmu.edu/).

The CMU database permits copying, modification and use in commercially sold products. The
motion data may not be resold directly, including in converted form. The database requests
the following acknowledgement:

> The data used in this project was obtained from mocap.cs.cmu.edu. The database was created
> with funding from NSF EIA-0196217.

Only the 16 retargeting samples used by this project are stored here. The original ASF/AMC
capture is not redistributed with the game.
