# LCD mecha motion atlas

`motion-atlas.png` is a 3840 × 1600 RGBA atlas consumed by Babylon's `SpriteManager` at
`/assets/lcd-platformer/mecha/motion-atlas.png`.

- Cell size: 320 × 320 pixels.
- Layout: 12 columns × 5 rows.
- Rows: `Idle_Loop`, `Walk_Loop`, `Jump_Start`, `Jump_Loop`, `Jump_Land`.
- Canonical authored view: side profile, facing right. Babylon mirrors the sprite immediately
  for left-facing movement.
- Visual construction: project-authored rigid mecha armor generated by
  `scripts/blender/mecha_motion.py`, with Blender Workbench object outlines.
- Motion source: Universal Animation Library Standard by Quaternius, downloaded from the
  author's OpenGameArt distribution.
- Source license: CC0 1.0 Universal / Public Domain Dedication.
- Source page: https://opengameart.org/content/universal-animation-library
- Source archive SHA-256:
  `18ff1a7215f4852b320203e8aaf02a1578b5c8eef9027fbaedfcedc7b85a3ac2`.
- Blender authoring version: 5.2.1 LTS, pinned and verified by `scripts/blender/setup.sh`.

Regenerate deterministically from the pinned inputs with:

```sh
npm run setup:authoring
npm run author:mecha-motion
```
